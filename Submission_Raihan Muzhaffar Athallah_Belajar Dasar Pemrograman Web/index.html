Tentang

Tentang Saya

Saya mahasiswa Teknik Telekomunikasi di Institut Teknologi Sepuluh Nopember (ITS) dengan ketertarikan besar pada sistem jaringan, infrastruktur cloud, dan analisis data. Fokus saya adalah memahami cara kerja jaringan, mengukur performanya, dan mengubah data teknis menjadi wawasan yang bisa ditindaklanjuti.

Saya terbiasa bekerja dengan metrik performa jaringan, menganalisis pola dan anomali, serta menerjemahkan data menjadi insight teknis. Saya juga tertarik pada operasional jaringan (NOC) serta integrasi antara jaringan dan teknologi cloud/computing.

Ke depannya, saya ingin berkembang menjadi network and cloud engineer, dengan minat khusus pada perkembangan 6G serta penerapan machine learning dan generative AI untuk analisis jaringan berbasis data.
