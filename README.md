## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ahayrai18/Dicoding_Project.git
cd Dicoding_Project
```

### 2. Choose a course

Open the directory for the course you want to review. Do not assume that a command used for one course will work for another, because each course may use a different runtime or set of dependencies.

### 3. Read the course instructions

Before running a project, check for files such as:

- `README.md` or other Markdown instruction files
- `pubspec.yaml` for Dart dependencies
- `requirements.txt` or notebook instructions for Python projects
- `package.json` for JavaScript projects
- HTML entry points and accompanying CSS or JavaScript files for web projects

These files help identify the required tools and the intended execution method.

## Working with a Course Folder

For a clear and reproducible workflow:

1. Keep each course's files in its own directory.
2. Preserve provided folder structures and file names when they are required by a course's automated tests or submission checker.
3. Install dependencies only after checking the instructions and configuration files for that course.
4. Keep documentation close to the project it describes.
5. Do not commit passwords, access tokens, API keys, private datasets, or other confidential information.
6. Avoid committing generated caches and local editor configuration unless they are required for the project.
